# Praxis — identidade visual

Marca e ícones do produto **Praxis** (peça de quebra-cabeça).

## Séries

| Série | Uso | Aparência |
|-------|-----|-----------|
| `1-*` | Tema **escuro** | Peça clara |
| `2-*` | Tema **claro** | Peça navy |

## Arquivos

|--------|-----|

| `og-praxis.png` | Open Graph |
