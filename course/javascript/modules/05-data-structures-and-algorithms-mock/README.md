# Data Structures and Algorithms — Mock Test

## Overview

Simulated HackerRank screening for **module 05 — Data Structures and Algorithms**: Big-O complexity, two pointers/sliding window, BFS/DFS, cycle detection, and dynamic programming.

This is **practice mode**: same section shape as common HackerRank JS screenings (instructions → MCQ → stdin/stdout coding), but shorter and more transparent than many production tests (all test cases visible, fixed pass score, no section lock-in).

## Rules

- **Duration:** 90 minutes
- **Passing score:** 70%
- **Sections:** instructions → multiple choice (8 questions) → coding challenge
- Do not refresh the page during the timed session (progress is stored locally).
