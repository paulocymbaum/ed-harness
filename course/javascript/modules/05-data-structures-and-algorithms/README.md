Interview and OA coding rounds reward **clear complexity reasoning** and a small set of reusable patterns. This module focuses on Big-O literacy and four high-leverage techniques.

## Checklist

- [ ] I can classify common loops as O(1), O(n), O(n²), O(log n)
- [ ] I can apply two pointers / sliding window on arrays/strings
- [ ] I can BFS vs DFS a graph or tree and explain queue vs stack
- [ ] I can detect a cycle in a linked list (Floyd) or graph
- [ ] I can state overlapping subproblems + optimal substructure for a tiny DP
