## Checklist

- [ ] I can sketch scale/CAP trade-offs at a high level
- [ ] I can structure a behavioral answer with STAR
- [ ] I ask clarifying questions before coding
- [ ] I name readability / testability trade-offs
- [ ] I improve a solution from brute force → better complexity with narration
