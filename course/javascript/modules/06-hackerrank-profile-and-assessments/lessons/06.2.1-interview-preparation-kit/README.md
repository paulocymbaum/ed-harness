## Context

The **Interview Preparation Kit (IPK)** is a curated HackerRank track organized **by topic** — Warmup, Arrays, Strings, Sorting, Search, Dynamic Programming, and more — instead of by difficulty or by random challenge feed. The goal is to practice with focus: work through one topic's set of problems in a row so the underlying pattern sticks, rather than jumping between unrelated challenge types.

## Focused practice beats random grinding

Random practice feels productive but spreads your attention across unrelated patterns. IPK groups problems so each session reinforces one recurring interview pattern at a time:

- `Warmup` — the easiest entry problems, meant to build momentum, not depth.
- `Arrays` — traversal, prefix sums, rotation-style array manipulation.
- `Strings` — parsing, matching, and string-building patterns.
- Everything else (`Dynamic Programming`, `Trees`, `Graphs`, ...) groups the harder, pattern-specific interview staples.

## Why picking the right track matters

If you know you're weak on array manipulation, working through the Warmup set repeatedly wastes time — you should route directly into the topic track that targets your gap.

## What to observe

- The four routing buckets are fixed — `arrays`, `strings`, `warmup`, and a catch-all for everything else.
- Unrecognized keywords don't error; they fall into the general/mixed bucket by design.
- The point of IPK is topic-first ordering, not difficulty-first ordering (that's what score bands are for).
- Picking a track deliberately based on a known weak spot is more efficient than working the kit top-to-bottom.
