# Algorithms

## Overview

Intermediate JavaScript course focused on **sorting**, **searching**, **saving data**, and **caching**. You already know arrays, objects, functions, and closures — this track teaches how to choose and implement algorithms with clear tradeoffs in time, space, and correctness.

## How to study

1. Start with **01 Algorithm Foundations** so Big-O, JS tooling (`Map`/`Set`), and correctness habits are in place.
2. Move to **02 Sorting**, then **03 Searching** — many search patterns assume sorted input or hash-backed lookups.
3. For each lesson: predict the complexity, implement in Node, then compare against the explanation once authored.
4. Use the content map in the UI to track which leaves still need projects and quizzes.
